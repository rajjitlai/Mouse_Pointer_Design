# Mouse Pointer Design

A modern, responsive robotics-themed landing page featuring beautiful custom mouse cursor effects and stunning visual design.

## ✨ Features

- 🎨 **Modern Design** - Sleek, futuristic interface with dark theme
- 🖱️ **Custom Mouse Cursor** - Beautiful dual-cursor effect (desktop only)
- 📱 **Fully Responsive** - Optimized for all devices:
  - Desktop (1920px+)
  - Tablet Landscape (1024px)
  - Tablet Portrait & Mobile Landscape (768px)
  - Mobile Portrait (480px)
- 🎯 **Touch-Optimized** - Smart cursor detection for touch devices
- ⚡ **Smooth Animations** - Hover effects and transitions throughout
- 🔍 **SEO Optimized** - Proper meta tags and semantic HTML
- 🎭 **Interactive Elements** - Clickable features, pagination, and navigation

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Media Queries, Clamp)
- Vanilla JavaScript
- Responsive Design Principles

## 🚀 Usage

1. Clone this repository
2. Open `index.html` in your browser
3. Enjoy the responsive experience!

## 📱 Responsive Breakpoints

- **1024px and below**: Sidebar moves to top, layout adjusts
- **768px and below**: Navigation stacks vertically, robot repositioned
- **480px and below**: Optimized for small mobile screens
- **Touch devices**: Custom cursor automatically disabled
